Fraud Prevention Curricula

Free teaching modules for AARP's Fraud Fighter Network and community organizations serving older adults. No registration, no sign in. Download and teach.

Where this material comes from #

Each module is the back of a detection model, turned around. Building a detection system requires describing a fraud scheme in exact operational terms: what the person running it has to obtain, in what order, and what traces that leaves behind. Read the other way, that same description says what the scheme looks like to the person it targets. A detection feature and a recognition cue are two renderings of one analysis: the model uses it to score an entity, and these modules use it to teach a person.

The facilitator guide #

Each module has its own facilitator guide: a timed delivery script broken into five to twelve minute segments, a 30 minute cut version for shorter slots, a specimen exercise with an answer key and the teaching reasoning behind each line, a section on the thirty seconds after a participant discloses it happened to them, room management guidance for the ways a session tends to go sideways, and a list of things never to say and why. That is what makes a module deliverable by a volunteer who has never met the author: everything a facilitator needs to run the session is in the guide, downloaded alongside the module itself.

Participant handouts #

Each module includes a one page participant handout: plain language, large type, and a tear off strip with the one rule and the reporting numbers to keep by the phone. The handout is what leaves the room, so it carries the action and the numbers and nothing else.
