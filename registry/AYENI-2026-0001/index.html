Curriculum module 01: Account takeover and synthetic identity

  • IdentifierAYENI-2026-0001
  • Version1
  • Published2026-06-30
  • AccessTier 1: public

Description #

A 45 minute reusable teaching module on account takeover and synthetic identity, written to be delivered by a trained volunteer with no technical background. Covers how both schemes work, the specific signals for each, the single action to take, and where to report. Includes delivery timing, a specimen exercise, facilitator notes for handling disclosures, and a derivation table showing that each recognition cue is a direct restatement of a measurement from the transaction and synthetic identity detection work in Initiative 2.
