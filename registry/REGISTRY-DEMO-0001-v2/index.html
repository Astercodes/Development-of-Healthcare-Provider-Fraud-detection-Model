README #

Registry mechanism demonstration (v2)

This is the current version of the registry mechanism demonstration artifact. It replaces REGISTRY-DEMO-0001, which stays live at its original address. This is what the version handling policy asks for: a new identifier per revision, the old page kept live, and a one line banner on each pointing to the other. Nothing is edited in place, and nothing is deleted.

Like v1, this is not a published methodology artifact. It is here so the registry's hashing, download, and version banner mechanics can be verified against real files before any real artifact is deposited.

What changed from v1

This README's wording, to make the two versions visibly distinguishable when compared side by side, which is also how you would tell them apart in a real revision.
