Curriculum module 03: AI generated impersonation

  • IdentifierAYENI-2026-0016
  • Version1
  • Published2026-06-30
  • AccessTier 1: public

Description #

A 45 minute reusable teaching module on calls and videos built from a real person's cloned voice or face, written to be delivered by a trained volunteer with no technical background. Covers how a scheme built on voice or video cloning works, the specific signals that separate it from a real emergency, the single action to take (hang up and call back on a number already saved, not one given during the call), and where to report. Includes a specimen voicemail exercise, facilitator notes for handling disclosures, and a live in session codeword exercise, the longest single block in the session.
