Description #

The working code behind the transaction fraud detection methodology paper: four Jupyter notebooks covering exploratory data analysis and three of the four trained classifiers, Decision Tree, K Nearest Neighbors, and Logistic Regression, each with training, an overfitting check, a classification report, ROC and precision recall curves, a confusion matrix, and a calibration curve. This deposit is not yet complete. The Random Forest notebook, the paper's recommended model for deployment, and the shared DataPreProcessing notebook that all three classifier notebooks import from, are not yet included and will be added to bring this to a runnable state.
